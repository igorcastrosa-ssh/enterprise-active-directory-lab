# enterprise-active-directory-lab
Process of building and securing an enterprise-style Active Directory environment using Windows Server, VMware, and Windows clients.

#Overview
This project demonstrates the design and deployment of an enterprise-style Active Directory environment using VMware Workstation and Windows Server.
The goal of this lab is to simulate a corporate IT infrastructure where I can practice:

- Identity and Access Management (IAM)
- Windows Server Administration
- Active Directory Domain Services
- DNS Management
- Group Policy
- Security Hardening
- Endpoint Security

- ## Lab Architecture

The environment consists of:

- Windows Server 2022 Domain Controller
- Windows 11 Client Machine
- VMware isolated network
